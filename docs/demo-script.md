# Demo 脚本

## 本地演示

1. 安装依赖并启动服务：`uv sync --extra dev`，然后 `uv run uvicorn backend.app.main:app --reload`。
2. 浏览器打开 `http://127.0.0.1:8000/`，页面预填一组模拟会话。
3. 确认目标、约束、决策、待办和工具结论已预填；调整输入预算，再点「构建上下文」。
4. 查看输入预算用量、系统/摘要/近期/工具分区、保留消息及未纳入列表。
5. 若工具结果超过截断阈值，点击工具消息下方的 artifact 链接验证原始结果可取回。
6. 将输入预算调到极低值后重新构建，确认 UI 显示服务端返回的明确错误；原始消息仍在编辑区，可恢复预算后再次构建。
7. 检查窄屏布局：缩小浏览器视口，确认表单与结果区改为纵向排列。

## 当前演示边界

样本是前端内置的短模拟会话，并非固定 10/40/80 轮评测数据。当前 UI 不提供轮次滑块、策略对比或异常注入面板；token 数是离线近似值，不能据此宣称真实模型质量或真实 token 用量。
