# AI logs and usage data

No full platform session or trace export was available in the project workspace during this implementation. The committed evaluation fixtures are synthetic and are not user logs. Runtime usage records are local metadata and are not a complete provider billing or platform usage export.

No real session/trace material is being published. Any future log publication requires reviewing the exact files for personal information, credentials and third-party confidential content, redacting secrets as `[REDACTED]`, and obtaining user approval before pushing.

`usage-heatmap/` is intentionally reserved for the user to populate later. No heatmap, usage chart or statistics are generated or inferred here.
